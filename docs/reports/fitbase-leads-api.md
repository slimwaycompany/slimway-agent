## 3. Теги

**Эндпоинт справочника:** нет (все варианты — `/tag`, `/lead-tag`, `/tags`, `/label` — возвращают 404).

**Формат в заявке:** поле `tags` — массив строк (имена тегов). Пример: `["tiktok"]`, `["Знакомые"]`, `["1"]`.

**Системные теги** (`tiktok`, `manual_import`, `no_phone`) не встретились в первых 10 лидах, но существуют в системе по условиям ТЗ. При синхронизации хранить как есть (string array → jsonb или отдельная таблица).

**Нет API для управления тегами** — теги нельзя получить отдельно, только через поле `lead.tags`.

**Фильтр по lead_id не поддерживается.** Комментарии привязаны к клиенту, не к заявке.

**Поля** (ожидаемые по Fitbase документации — не удалось получить примеры, т.к. у первых 5 лидов нет linked client_id с комментариями):

## Предложение для синхронизации

### Стратегия: полная синхронизация

Инкрементальной (по дате изменения) нет — все filter-параметры для этого не работают. Единственный вариант: **полная перезагрузка** через `paginateGet('/lead', {page_size:100})`.

### Частота
- Лиды + задачи: каждые 5 минут (~22 сек, очень малый overhead на Render free tier).
- Воронки/этапы: один раз при запуске, потом раз в час (они меняются редко).
- Пользователи и источники: раз в сутки.

### Ключи для связи

| Объект | Ключ |
|--------|------|
| Заявка | `lead.id` → `fb_leads.fitbase_id` |
| Клиент | `lead.client_id` → `fb_clients_cache.fitbase_client_id` |
| Этап | `lead.funnel_step.id` → `crm_funnel_steps.fitbase_id` |
| Воронка | `lead.funnel_step.purchase_funnel.id` → `crm_funnels.fitbase_id` |
| Менеджер | `lead.manager.full_name` → `app_users.display_name` (ручное сопоставление в настройках) |
| Источник | `lead.advertising_source.id` → `crm_ad_sources.fitbase_id` |

### Архивация
Нет фильтра «архивные vs активные». Все 936 лидов выдаются вместе. Лиды в «Отказ» (id=-2) — это архивные по факту. Признак «в архиве» придётся добавлять в схеме самостоятельно.

### Теги
Массив строк из API сохранять в jsonb. При ручном добавлении тегов в настройках нашей CRM — сверять по имени строки.

### Менеджеры
Fitbase `full_name` → наш пользователь: ручной словарь сопоставления в настройках (таблица `app_users.fitbase_display_name`).
