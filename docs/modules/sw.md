# Модуль: SW — ИИ-ассистент (рабочее имя JARVIS)

Чат в claude.ai: «SW (ассистент)» · Файл: `docs/modules/sw.md`

## Назначение
SW — собственный ИИ-ассистент SlimWay: одно ядро (оркестратор с инструментами CRM, правами и журналом) и несколько каналов — Telegram-бот SW, Яндекс Алиса (приватный навык), SW Desktop на ПК, позже чат во вкладке рабочего окна. Для владельца и сотрудников, не для клиенток. В перспективе — универсальный личный и корпоративный помощник.

Сюда же вошла идея «Голос студии» (Алиса/Станция как голос студии: музыка, таймеры, объявления) — как будущий канал «плеер зала».

## Ключевые решения
- **Мобильная версия — сразу в каждой задаче (04.11.2026).** Любой новый или изменённый экран сразу верстается под телефон (≤640), планшет и компьютер.
- **Имя — SW** (Сергей, 26.11.2026). JARVIS — рабочее название из ТЗ.
- **Анализ концепции (26.11.2026):** документ «SLIMWAY JARVIS — технический анализ» https://claude.ai/artifact/7GnVJgvue36LhgsTuYrHLi (предложения, Сергей ещё не утвердил):
  - Ядро — внутри slimway-agent (Node/TS, Supabase, права `src/core/permissions.ts`, журнал), не отдельная система. n8n не нужен — есть cron-job.org и `/run/*`.
  - «Мозг» — облачная модель (Claude/OpenAI) через свой адаптер; локальная модель на i3-10100 без GPU — только запасная.
  - Голос локально на ПК: wake word (openWakeWord/Porcupine), распознавание (Vosk / faster-whisper small), синтез (Silero).
  - Алиса — приватный навык `POST /sw/alice`; таймаут ответа 4,5 с, текст/озвучка до 1024 символов; частые вопросы — быстрые команды без ИИ. Требует платный Render (free засыпает). Навык сам заговорить не может: музыка/таймеры/объявления — через свой плеер зала или сценарии Умного дома.
  - Уровни действий: 1 чтение · 2 изменение (подтверждение в Telegram) · 3 критичное (только админ + повтор пароля). `crm_checkout`/`crm_refund` SW не вызывает никогда. ИИН и удостоверения в модель не отправлять; телефоны маскировать.
  - Telegram-бот SW — отдельный служебный бот, не клиентский (`src/telegram/bot.ts` не смешивать).
  - WhatsApp/Instagram — только после выбора агрегатора (`aggregator.md`, ⚪).
- MVP: только чтение, только админ — Telegram (текст+голосовые) + Алиса + утренняя сводка; 6–8 инструментов (записи, факт дня, выручка, план/факт, заявки, поиск клиента, аппараты, смены). Ориентир AI-расходов 15–45 $/мес.

## Пересечения с другими модулями
- `reports.md` — числа SW должны совпадать с Отчётами (эндпоинты `/kviz/api/metrics/*`: fact-day, daily, plan-fact, renewals, trial-peak).
- `crm-schedule.md` — записи, аппараты, правило переноса (продавец — только на сегодня).
- `crm-leads.md` — новые/необработанные заявки.
- `logins.md` — права сотрудников, SW работает с правами того, кто спрашивает.
- `telegram-bot.md` — клиентский бот, отдельный от SW.
- `aggregator.md`, `chats.md` — мессенджеры (этап 7).
- `control.md`, `ovcharka.md` — основа будущих агентов.
- `tv.md`, `infra.md` — плеер зала / платный Render.
