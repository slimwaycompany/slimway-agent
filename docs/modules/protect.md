## Таблицы

## Ключевые решения
- Все таблицы с RLS без политик, доступ только с сервера через `service_role`. Функции `crm_checkout` / `crm_refund` / `crm_shift_expected_cash` — execute отозван у anon и authenticated.
- Секреты только в env (Render), не в коде. `.env` в `.gitignore`.
- ИИН и данные удостоверений видны полностью только в открытой анкете, в списках маскируются, каждый просмотр анкеты пишется в журнал. Фото клиентов — приватный bucket, ссылки временные.
- Мониторинг «жив ли агент и CRM» — отдельный сервис со своим окном, чтобы работал, даже если основной упал (решено 28.10).
- Безопасность обсуждается в отдельном чате «Протект» (решено 28.10).
