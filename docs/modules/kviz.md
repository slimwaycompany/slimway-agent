# Модуль: Квалификация (звонки)

Чат в claude.ai: «Менеджер и квалификация» · Файл: `docs/modules/kviz.md`

## Назначение
Пошаговые окна квалификации клиента во время звонка (расстояние, возраст, противопоказания, зона, сроки).

## Где код
- `kviz/client/src/pages/QuizPage.tsx` — пошаговая квалификация (вопросы, подсказки, ответы, живое резюме)
- `kviz/client/src/pages/HomePage.tsx` — список квалификаций
- `kviz/client/src/pages/NewPage.tsx` — новая квалификация (имя и телефон)
- `kviz/client/src/pages/SummaryPage.tsx` — итог квалификации (только просмотр)
- `kviz/client/src/pages/ResultsPage.tsx` — результаты (сводный экран после квалификации)
- `kviz/client/src/pages/HistoryPage.tsx` — история
- `kviz/client/src/components/` — `AskPanel`, `ExitDialog`, `LiveResult`, `QuickReplies`, `ScriptItem`
- `src/http/kviz.ts` — серверный маршрутизатор `/kviz/api/*`

## Таблицы
- `qualify_sessions` — сессии квалификации (имя, телефон, ответы, резюме)

## Ключевые решения
- **Мобильная версия — сразу в каждой задаче (04.11.2026).** Любой новый или изменённый экран сразу верстается под телефон (≤640), планшет и компьютер; задача без мобильной вёрстки не считается выполненной. Проверка `npm run check:mobile`, скриншоты 375 и 1440 в отчёте.
- Первое окно — имя и телефон. Завершённые квалификации только для просмотра. Три колонки: вопросы/подсказки, ответы, живое резюме.

- 26.10: для переписки делаем Скриптолог (отдельный модуль); звонковую квалификацию не трогаем, может быть скрыта.
