# Модуль: TikTok-лиды

Чат в claude.ai: «TikTok лиды» · Файл: `docs/modules/tiktok.md`

## Назначение
Лиды из TikTok (Leads Center, сообщения в директ, Message Assistant) попадают в Fitbase в воронку «Новые заявки».

## Где код
- Google Apps Script `tiktok-fitbase-sync` (вне репо): Google Таблица (интеграция Leads Center) → Fitbase, триггер каждые 5 мин
- В репо пока ничего (дополнить, если появится)

## Таблицы
- Google Таблица Leads Center (вне Supabase)

## Ключевые решения
- Albato отказались — своя синхронизация через Google Sheets + Apps Script.
- Автосбор лидов в Leads Center включён; политика конфиденциальности прошла проверку, «Mark as lead» в директе работает → лид в таблицу → в Fitbase.
- TikTok отклонил заявку на API (окт. 2026).
- Лид без телефона всё равно идёт в Fitbase: вместо номера — имя в TikTok, менеджер добавит телефон позже. Клиентов автоматически не создаём (чтобы не было дублей) — менеджеры создают сами.
- Проблема: TikTok отдаёт номер профиля, он может быть старым. Временное правило: если номер с карточки не отвечает — менеджер смотрит переписку в TikTok.

## Сделано
### до 28.10.2026 · вне репо · синхронизация Leads Center → Fitbase
- Работает на Apps Script (единственное, что осталось на Apps Script).

## Открытые баги
- Неверный телефон: номер профиля TikTok вместо номера, который клиентка написала в чате.

- ИИ-агент: добавлять контекст переписки в описание карточки; задачи менеджеру (нет клиента в базе → задача создать клиента; есть клиент → поправить задачу), по возможности двигать карточки по этапам.
