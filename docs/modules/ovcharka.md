# Модуль: Овчарка (окно уведомлений)

Чат в claude.ai: «Агент и овчарка» · Файл: `docs/modules/ovcharka.md`

## Назначение
Вкладка «Агент»: тревоги для менеджеров, лента действий агента, кабинет агента. И сторож, и помощник.

## Где код
- `public/window-app.js` — фронт `/window`
- `src/jobs` — `/run/watch`, `/run/watch-brief` (дополнить)

## Таблицы
- `watch_alerts` — тревоги
- `agent_events` — лента

## Ключевые решения
- Одно общее окно на всех; уведомления в правом нижнем углу, имена клиентов сокращены.
- Смотрит только «Новые заявки». Новый лид — сразу; «тревога», если через 5 мин нет задачи. Максимальная дата задачи — 7 дней.
- «Сейчас важно»: новый лид, не пришёл на запись, абонемент заканчивается, абонемент закончился + задачи, которые поставил агент.
- Раскладка на компьютере: слева лента агента, по центру «Сейчас важно», справа закрытые за 24 ч.
- Кабинет агента: девушка за компьютером + немецкая овчарка (векторная SVG-иллюстрация в цветах бренда), реагирует на реальное состояние агента; клик по собаке — лает, по девушке — говорит, чем занята.
