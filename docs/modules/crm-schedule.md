## Ключевые решения (собраны 27.10)
- **Мобильная версия — сразу в каждой задаче (04.11.2026).** Любой новый или изменённый экран сразу верстается под телефон (≤640), планшет и компьютер; задача без мобильной вёрстки не считается выполненной. Проверка `npm run check:mobile`, скриншоты 375 и 1440 в отчёте.
- Неделя пн–вс, слева время 07:00–23:00, часовые ячейки; запись на точное время с шагом 30 мин внутри ячейки.
- Записать можно только клиента с оплаченным абонементом (оплата = продажа в Кассе). Бесплатные услуги (is_free_booking: пробное, замер) — без кассы.
- При записи: клиент → его активные абонементы (может быть несколько) с остатком сеансов и статусом активации → доступные аппараты. Один абонемент — выбирается сам. Ошибся ячейкой — запись переносится в выбранное время.
- Активная + завершающая фаза: две последовательные брони; завершающая сразу после окончания активной по времени сеанса аппарата. Нет места — предупредить и предложить ближайшее время.
- Вместимость = работающие и свободные аппараты нужного вида; маленький индикатор свободных, меняется при выборе абонемента.
- «Кто проводит» — консультанты (пока из пользователей; позже окно сотрудников).
- Сеанс списывается по отметке «Пришёл». Неявка сеанс не сжигает (`lessons.no_show_burns_session` = false), правила — галочками в Настройки → Занятия.
- Абонемент активируется первым посещением (функция активации заготовлена на этапе 2).
- Услуги (разовое посещение, замер InBody) работают похоже на абонементы — для другого отчёта.

### Решения 05.11.2026 (после разбора Fitbase)
- **Завершающая фаза — автобронь.** Если в составе абонемента есть завершающая фаза, при записи на активную система сама бронирует завершающий аппарат сразу после окончания активной. Две брони связаны: перенос и отмена — вместе. Нет места — предложить ближайшее время, где свободны оба.
- **Один клиент на один аппарат.** Пересечения броней одного аппарата запрещены на уровне базы (exclusion constraint), не только в форме. Клиент не может быть одновременно на двух аппаратах.
- **Аппарат подбирается автоматически:** свободный нужного вида и наименее загруженный за день; менеджер может сменить.
- **Доступные аппараты — из состава абонемента клиента** (`crm_client_plan_items`), никаких галочек абонементов на шаблоне занятия.
- **Отмена:** ранняя — не позже чем за 720 мин (12 ч) до начала; позже — «Поздняя отмена». Правила включает/выключает админ в Настройки → Занятия: `lessons.early_cancel_minutes` (720), `lessons.late_cancel_burns_session` (вкл/выкл), `lessons.no_show_burns_session` (false).
- **Статусы брони:** Записан, Подтверждено, Пришёл, Не пришёл, Поздняя отмена, Отменена. «Ожидает оплаты» и лист ожидания не нужны — без оплаты не записываем.
- **Вид — переключатель «День по аппаратам» / «Неделя».** По умолчанию «День по аппаратам» (колонки = аппараты, как «По залам» в Fitbase); последний выбор запоминается у пользователя. На телефоне — день, аппараты листаются по горизонтали внутри сетки.
- **Длительность:** пробное — 20 мин; остальное — по `session_minutes` аппарата.
- **Время работы 07:00–22:00** (как график залов в Fitbase) — поправить `schedule.day_end` на 22:00.
- **Тренер** подставляется сам — залогиненный сотрудник, можно сменить.

### Как устроено в Fitbase (разбор 05.11.2026)
- Залы = аппараты (Infrashape, Infrastep, Rollshape 1–4, Vacuactiv 1–3), у каждого «постоянный график» 07:00–22:00 с автопродлением.
- Занятие = тип тренировки + тренер + место (аппарат) + дата/время + длительность (30, пробное 20). На каждого клиента — отдельное персональное занятие, в нём запись клиента.
- Вместимость персонального занятия 3–4 при одном аппарате; проверки пересечений нет (05.11 на Vacuactiv 1 стояли 19:00–19:30 и 19:15–19:45, одна клиентка одновременно на Vacuactiv 1 и 3).
- Завершающая фаза отдельно не бронируется (Rollshape 2 и 4 пустые неделями). Нагрузка перекошена: Vacuactiv 1 до 19 занятий в день, Vacuactiv 2–3 по 2–10.
- Какие абонементы можно записать — галочки на шаблоне занятия.
- Статусы записи: Не подтверждено, Подтверждено, Отказался, Пришёл, Не пришёл, Поздняя отмена, В ожидании, Ожидает оплаты. Ранняя отмена — 720 мин.
- Есть: перенос занятия, замена тренера, «Написать клиентам», повторение по шаблону, комментарий.
