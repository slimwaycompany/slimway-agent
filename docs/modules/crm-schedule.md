## Назначение

## Ключевые решения (собраны 27.10)
- Неделя пн–вс, слева время 07:00–23:00, часовые ячейки; запись на точное время с шагом 30 мин внутри ячейки.
- Записать можно только клиента с оплаченным абонементом (оплата = продажа в Кассе). Бесплатные услуги (is_free_booking: пробное, замер) — без кассы.
- При записи: клиент → его активные абонементы (может быть несколько) с остатком сеансов и статусом активации → доступные аппараты. Один абонемент — выбирается сам. Ошибся ячейкой — запись переносится в выбранное время.
- Активная + завершающая фаза: две последовательные брони; завершающая сразу после окончания активной по времени сеанса аппарата. Нет места — предупредить и предложить ближайшее время.
- Вместимость = работающие и свободные аппараты нужного вида; маленький индикатор свободных, меняется при выборе абонемента.
- «Кто проводит» — консультанты (пока из пользователей; позже окно сотрудников).
- Сеанс списывается по отметке «Пришёл». Неявка сеанс не сжигает (`lessons.no_show_burns_session` = false), правила — галочками в Настройки → Занятия.
- Абонемент активируется первым посещением (функция активации заготовлена на этапе 2).
- Услуги (разовое посещение, замер InBody) работают похоже на абонементы — для другого отчёта.
