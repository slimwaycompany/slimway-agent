# Модуль: Менеджер (чек-лист смены, закрытие смены)

Чат в claude.ai: «Менеджер и квалификация» · Файл: `docs/modules/manager.md`

## Назначение
Вкладка «Менеджер»: ежедневный чек-лист смены с задачами по времени, отметка на смене, закрытие смены (X-отчёт из Fitbase).

## Где код
- `kviz/client/src/pages/manager/ManagerPage.tsx` — чек-лист задач смены (общие + личные задачи), отметка на смене
- `kviz/client/src/pages/manager/CashClosing.tsx` — закрытие кассовой смены (X-отчёт из Fitbase)
- `kviz/client/src/pages/manager/AdminPage.tsx` — вкладка «Admin» (отчёт смен, шаблоны задач — только admin)
- `src/http/manager.ts` — API `/kviz/api/manager/*`: шаблоны задач, отметки выполнения, смены, webhook расписания
- `src/http/cash.ts` — API `/kviz/api/cash/*`: данные закрытия кассы из Fitbase, сохранение X-отчёта
- `src/http/shifts.ts` — API `/kviz/api/shifts/*`: открытие/закрытие рабочих смен сотрудников

## Таблицы
- `manager_task_templates` — шаблоны задач смены (title, slot_time, weekend_time, weekdays, scope shared/personal, category, sort, is_active)
- `manager_task_done` — отметки выполнения задач за день (template_id, task_date, done_by, done_at)
- `cash_closings` — закрытия кассы (shift_date, counted_cash, сводка операций из Fitbase, номер закрытия)
- `staff_shifts` — смены сотрудников (user_id, date, status open/closed, start/end time)
- `fitbase_operations` — операции Fitbase (читаются при закрытии кассы)
- `sync_state` — метка последней синхронизации операций

## Ключевые решения
- **Мобильная версия — сразу в каждой задаче (04.11.2026).** Любой новый или изменённый экран сразу верстается под телефон (≤640), планшет и компьютер; задача без мобильной вёрстки не считается выполненной. Проверка `npm run check:mobile`, скриншоты 375 и 1440 в отчёте.
- Общие задачи дня (сторис, вызвать уборщицу, открыть/закрыть смену): выполнил кто-то один — закрыто у всех. Отметка на смене — личная.
- Закрытие смены (из Fitbase, 00:01–23:59): продажи, возвраты, изъятия, внесения → шаблон `templates/zakrytie-smeny.xlsx` (безнал-расход, монеты, «сдал» + ФИО), подсчёт купюр, печать по шаблону; второй лист — все операции дня.
- Остаток = открытие + приход − расход. Номера закрытий продолжаются с 89. Открытие = вчерашнее закрытие.
- Тестовый режим: в Fitbase ничего не открывать и не закрывать (только чтение).
- `GET /kviz/api/cash/sync-time` — admin-only (добавлена проверка роли 30.10.2026). `POST /cash/sync` и отчётные эндпоинты `/reports/sales`, `/reports/occupancy` — тоже admin. Эндпоинты `/cash/today`, `/cash/closing`, `/cash/closing-template` — доступны всем авторизованным.
