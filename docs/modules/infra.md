# Модуль: Инфраструктура, вход, оболочка

Чат в claude.ai: «Агент и овчарка» · Файл: `docs/modules/infra.md`

## Назначение
Сервер, деплой, cron, вход сотрудников и оболочка рабочего окна (вкладки, боковые кнопки).

## Где код
- `src/index.ts` — точка входа, маршруты
- `src/http` — маршруты, middleware входа
- `src/jobs` — задачи для `/run/*`
- `public/` — оболочка и `/window`
- `kviz/client` — React-приложение вкладок
- (дополнить при следующей задаче)

## Таблицы
- `app_users` — сотрудники, роли admin / manager; пароль проверяет `app_check_login`
- `job_runs`, `job_locks` — запуски и блокировки задач

## Ключевые решения
- Render free (512 МБ), автодеплой из `main`; cron-job.org будит и запускает задачи. Часовой пояс Asia/Yekaterinburg.
- cron: `/health` 7:25, 7:35, 7:45, 7:55; trial каждые 5 мин 8–22; budget в 8,10,…,22; daily-summary 22:25 будни / 20:55 выходные.
- Экран выбора — только сразу после входа; при перезагрузке — та же вкладка (23.10).
- Порядок вкладок (28.10): Менеджер → Агент → Расписание → Клиенты → Воронка → Касса → Квалификация → Замеры → Отчёты → Настройки (только admin). Боковые кнопки идут по этому порядку.
- Повторный клик по активной вкладке = вернуть её на начальный экран.
- Мониторинг «жив ли агент и CRM» — будет отдельным сервисом со своим окном (28.10), чтобы работал, даже если основной упал.
- Батник `slimway_start.bat` у Сергея открывает Chrome с рабочими вкладками.
