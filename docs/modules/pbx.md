# Модуль: Виртуальная АТС (OnlinePBX)

Чат в claude.ai: «АТС (OnlinePBX)» · Файл: `docs/modules/pbx.md`

## Назначение
Телефония студии SlimWay на OnlinePBX, встроенная в систему: приём событий звонков (вебхук), журнал звонков и событий, привязка внутренних номеров к сотрудникам и клиентам, данные для Контроля (скорость ответа, B.A.N.T., очередь заявок). Для сотрудников — менеджеры и ОКК; для админа — настройки АТС.

Статус на 21.11.2026: модуль заведён, объём задачи «виртуальная АТС внутри системы» ещё не описан (см. «Следующее»).

## Где код
- `src/http/pbx.ts` — вебхук `POST /hooks/onlinepbx?key=` (200 сразу, разбор в фоне), `GET /hooks/onlinepbx?key=` (проверка доступности), Settings API `/kviz/api/pbx/*`
- `src/http/pbx.ts` → `runPbxSync()` — опциональный pull истории из OnlinePBX API `/api/v1/history`, эндпоинт `/run/pbx-sync` в `src/index.ts`
- Клиент: `PbxSection` в Настройках (раздел «Связи и данные → АТС»): webhook URL, внутренние номера (CRUD), вкладки «Звонки» и «События»
- Право `settings.pbx`

## Таблицы
- `pbx_events` — сырые события вебхука
- `pbx_calls` — звонки (ключ `call_uuid`, upsert), привязка к `crm_leads` / `fitbase_clients_cache` по `phone_digits`
- `pbx_extensions` — внутренние номера ↔ сотрудник
- SQL по этим таблицам в задаче 65 помечен как «нужен»; выполнен ли он в Supabase, в файле не отмечено — проверить

## Ключевые решения
- **Вебхук отвечает 200 немедленно**, разбор асинхронный: insert в `pbx_events`, затем upsert в `pbx_calls` (решение из задачи 65, 18.11.2026).
- **Занятость менеджера — только по звонкам АТС** (решено 18.11.2026). Остальное снимается кнопкой «не по вине менеджера» в Контроле.
- **Время фиксации после звонка** — одна настройка на 30–60 сек, используется и очередью заявок, и дозаполнением B.A.N.T. (решено 18.11.2026).
- **Ошибки АТС/синка = «нет данных», не нарушение** (решено 18.11.2026, правило для Контроля).
- **Слой источников:** проверки Контроля читают АТС через отдельный слой, чтобы при переезде на свою CRM поменять источник, а не правила.
- **Рабочая идея (не решена):** софтфон/виджет OnlinePBX внутри окна агента, звонок в один клик через API.
