# Задача 48-4 — Напоминание 24ч без подарка; отмена только после подтверждённого удаления

## ЧАСТЬ 1 — Текст напоминания за 24 ч без подарка

Решение Сергея 13.11: напоминание получают и повторные клиенты, подарок им не положен.

Новые тексты trial_24h (дословно):
- RU: «Здравствуйте! 🌸 Напоминаем, завтра в {Время} ждём Вас на пробное посещение в SlimWay 💚»
- KZ: «Сәлеметсіз бе! 🌸 Еске саламыз, ертең {Время} SlimWay-де сынақ сабағына күтеміз 💚»

Строку «🎁 И не забудьте: замер InBody — Вам в подарок!» и «🎁 Ұмытпаңыз: InBody өлшеуі — Сізге сыйлық!» удалить везде в job.

Уже поставленные в EasyChat напоминания не трогать.

## ЧАСТЬ 2 — Отменять напоминание только после подтверждённого удаления

Три места:
1. Terminal status block в `scriptologReminders.ts` (статусы 1/2/3/4)
2. Orphan cancel block в `scriptologReminders.ts` (конец функции)
3. HTTP DELETE `/api/scriptolog/reminders/:id` в `scriptolog.ts`

Правила:
- `cancelled` ставить, только если `deleteDelayed` прошёл успешно ИЛИ EasyChat ответил 404
- При другой ошибке — строку не трогать (останется `scheduled`), в лог причину
- При 401/403 — существующая тревога про токен (`upsertTokenAlert` в job, 502 в HTTP)
- В DRY — как сейчас, только лог (DRY уже обрабатывается внутри `deleteDelayed`)
- HTTP DELETE: также разрешить статус `scheduled` (сейчас только `pending`)

Добавить helper `safeDeleteDelayed` в `src/core/easychat.ts`:
- возвращает `'ok' | 'gone' | 'auth' | 'error'`
- `'ok'` — удалено / DRY-лог (нет броска)
- `'gone'` — EasyChat ответил 404 (сообщение уже нет)
- `'auth'` — 401/403
- `'error'` — иная ошибка (логирует внутри)
