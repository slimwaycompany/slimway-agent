# ЗАДАЧА 56-1 — Админ не видит «Должности», пустой список должностей в карточке

## Причина

`kviz/client/src/pages/crm/StaffPage.tsx:674`: `const { role } = usePerm()`. `usePerm(key, level)` возвращает `boolean`, поэтому `role = undefined`, `isAdmin = false`.

Следствия у админа:
- нет вкладок «Сотрудники | Должности»
- `/api/positions` не загружается
- выпадающий список «Должность» пустой
- в карточке красное «Должность не задана — нет доступа ни к чему», хотя в `app_users.position_id` должность есть
