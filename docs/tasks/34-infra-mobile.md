ЧАСТЬ 1 — Общие правила и общие компоненты
═══════════════════════════════
- Точки перелома во всём проекте одинаковые: ≤ 640 — телефон, 641–1024 — планшет, > 1024 — компьютер. Вынести в CSS-переменные / общий файл, не писать в каждом компоненте свои
- Общие компоненты (в kviz/client/src/components/ui/ или аналог), чтобы все страницы использовали их:
  - ResponsiveTable — на компьютере таблица; на телефоне карточки (строка → карточка «подпись: значение»), либо горизонтальная прокрутка ВНУТРИ блока с закреплённой первой колонкой — для широких отчётных таблиц (продажи, метрики, ЗП, загруженность)
  - Modal → на телефоне полноэкранный лист снизу (bottom sheet): шапка с заголовком и крестиком закреплена, содержимое прокручивается внутри, кнопки действий закреплены снизу
  - FilterBar — фильтры переносятся по строкам; на телефоне сворачиваются в кнопку «Фильтры (N)» с выезжающей панелью
  - PageHeader — заголовок + действия; на телефоне действия уходят под заголовок или в меню «⋯»
- Глобально:
  - нигде нет горизонтальной прокрутки страницы (scrollWidth ≤ ширины окна)
  - поля ввода — шрифт ≥ 16px (иначе iPhone приближает страницу при фокусе); правильные inputmode/type: телефон tel, суммы и сантиметры decimal, даты date
  - кнопки и строки-ссылки — зона нажатия ≥ 44×44 px
  - длинные имена и суммы переносятся/обрезаются с «…», не вылезают из карточек; деньги — ₸ с пробелами
  - графики — ширина по контейнеру, подписи не налезают, на телефоне меньше подписей оси и тултип по нажатию
  - учитывать безопасные зоны iPhone (env(safe-area-inset-*)) для закреплённых элементов
  - hover-эффекты не должны быть единственным способом что-то увидеть — всё доступно нажатием

═══════════════════════════════
- /login — по центру, на телефоне на всю ширину с отступами 16px, кнопка на всю ширину
- Экран выбора — кнопки столбиком на всю ширину
- Верхние вкладки на телефоне: одна строка с горизонтальной прокруткой (без полосы), активная вкладка автоматически прокручивается в видимую зону, бейджи видны; панель закреплена сверху
- Боковые вертикальные кнопки на телефоне и планшете < 1024 — скрыты (как сейчас на телефоне), на 1024+ — как сейчас

- iframe вкладок — на всю оставшуюся высоту (100dvh минус шапка), без двойной прокрутки

ЧАСТЬ 3 — Вкладки по очереди
═══════════════════════════════
Пройти КАЖДЫЙ экран, на каждой ширине — без горизонтальной прокрутки, ничего не обрезано, всё нажимается:
- Менеджер: чек-лист, отметка смены, рилсы; «Закрытие смены» — лист снизу, подсчёт купюр в 2 колонки на телефоне (1 колонка на 375), итоги закреплены снизу
- Агент (/window, public/window-app.js): лента тревог, кабинет агента — сцена масштабируется по ширине, облачко не уходит за край
- Расписание, Воронка — заглушки читаемы
- Клиенты (CRM): список карточками, поиск сверху; анкета клиента — поля в 1 колонку, фото/ИИН не ломают вёрстку
- Касса: выбор клиента, корзина, оплата — по шагам сверху вниз, итог и кнопка «Оплатить» закреплены снизу
- Квалификация: три колонки (вопросы / ответы / резюме) → на телефоне переключатель «Вопрос / Ответы / Резюме» или одна колонка, кнопки Назад/Далее закреплены снизу
- Замеры: форма нового замера — по одной зоне в строку, крупные поля; InBody-диалог (3 кнопки, камера) — на весь экран; экран результата и кнопка «Перейти в отчёт»
- Скрытый отчёт клиента: фигура сверху (~60–70vh, плашки зон не налезают — на телефоне подписи короче или показ по нажатию), ниже «Потеряно», график, замеры, InBody; попап зоны — лист снизу; «Полный лист InBody» — блоки в одну колонку
- Отчёты: доска колонок → колонки друг под другом; каждый отчёт (Продажи, Задачи, Смены, Замеры, InBody, Результаты студии, Занятия, Факт дня, Дневной такт, Метрики по дням, ЗП, ТБУ и т. д.) — фильтры через FilterBar, таблицы через ResponsiveTable, drill-попапы — листом снизу; сетка загруженности «день × час» — прокрутка внутри блока с закреплённой колонкой даты
- Настройки: разделы списком → раздел на весь экран с «← Назад»; формы в 1 колонку
- /r/:token (ссылка для клиента) — мобильная версия в первую очередь, проверить на 375 и 390
- /results (экран ТВ) — на телефоне счётчики столбиком, шрифты уменьшаются, не вылезают
- Печать бланка и закрытия смены — не трогать вёрстку печати (A4), только кнопки вызова
- Скриптолог (/scriptolog в боковой панели Chrome, ширина ~320–400px) — проверить на 360, ничего не обрезано
