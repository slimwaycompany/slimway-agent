ЗАДАЧА 99-1 — Печать закрытия смены точь-в-точь как Excel-шаблон
═══════════════════════════════════════════════

Задевает модули: crm-kassa, reports (печать из «Закрытия кассы»). Прочитай их файлы.
SQL-файлы и миграции не создавать. SQL для задачи не нужен.
Почему переделка: в задаче 99 `kviz/client/src/lib/closingDocHtml.ts` печатает свою таблицу «Итоги смены / Показатель / Сумма» и «Покупюрную ведомость» — это НЕ шаблон Сергея. Свою разметку больше не придумывать.

- Открой `templates/zakrytie-smeny.html` — это готовая HTML-копия `templates/zakrytie-smeny.xlsx` один в один (сгенерирована из xlsx: ширины колонок, высоты строк, объединения, рамки, шрифты, масштаб «вписать на 1 страницу A4»). Образец заполненного документа — `templates/zakrytie-smeny-primer.pdf`.

═══ ЧАСТЬ 1 — closingDocHtml = шаблон ═══
- Переписать `kviz/client/src/lib/closingDocHtml.ts`: импортировать шаблон как строку (`import tpl from '../../../../templates/zakrytie-smeny.html?raw'`, либо скопировать файл в `kviz/client/src/assets/zakrytie-smeny.html` и импортировать оттуда с `?raw` — выбери то, что собирается Vite) и заменить плейсхолдеры `{{...}}` значениями. Всё остальное в HTML НЕ менять: ни теги, ни классы, ни размеры, ни стили, ни порядок строк. Не добавлять заголовков, итогов, «Излишек/Недостача», «Итоги смены», «Кассир/Подпись».
- Каждое значение — через HTML-экранирование. Пустое / null / undefined → пустая строка (никаких «undefined», «NaN», «null»).
- Значения плейсхолдеров:
  - `{{closing_no}}` — closing_no.
  - `{{org}}` — `ТОО “<legal_name>” БИН:<bin>` из crm_branches (если legal_name или bin пусто — пустая строка).
  - `{{address}}` — `<city>, <address>` филиала (пустые части пропустить).
  - `{{opened_at}}` — время открытия смены, `{{closed_at}}` — время формирования документа (closing_doc_at / closed_at). Формат `ДД.ММ.ГГГГ ЧЧ:ММ`, часовой пояс Asia/Almaty (UTC+5).
  - `{{opening_cash}}` — сумма на начало смены.
  - `{{kassa_name}}` — `Касса 1  <city>, <address>` (две пробела после «Касса 1», как в шаблоне).
  - `{{cash_in}}` — приход наличных = наличные продажи + доплаты + внесения; `{{cash_out}}` — расход = возвраты наличными + изъятия; `{{cash_left}}` = opening_cash + cash_in − cash_out.
  - `{{card_in}}` — приход безнала за смену; `{{card_out}}` — возвраты безналом.
  - `{{n500}} {{n1000}} {{n2000}} {{n5000}} {{n10000}} {{n20000}}` — количество купюр из cash_count; `{{c200}} {{c100}} {{c50}} {{c20}} {{c10}} {{c5}} {{c2}} {{c1}}` — количество монет. Нет данных — 0 (как в шаблоне).
  - `{{counted_cash}}` — «Сумма наличных в кассе» = сумма по купюрам и монетам.
  - `{{handed_sum}}` — то же число (строка «Денежные средства ₸ … сдал»); `{{handed_fio}}` — ФИО закрывшего смену (display_name учётки).
- Деньги — целые с разделителем тысяч пробелом (`155 080`), без «₸» (знак уже стоит в заголовках шаблона).
- Если в снимке `closing_doc` нет legal_name / bin / city / address / opened_at — при `PATCH /shifts/:id/close-with-doc` добавить их в снимок; для старых закрытий без них — подставить текущие реквизиты филиала из `GET /shifts/:id/closing-data` (или эндпоинта «Закрытия кассы» в Отчётах).
- Печать — как сейчас, через iframe.srcdoc, из Кассы (CloseShiftWithDoc) и из Отчётов (KassaClosingsSection) — одна функция.
