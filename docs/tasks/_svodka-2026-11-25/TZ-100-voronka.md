═══ ЧАСТЬ 1 — Фильтры на доске ═══
- Панель фильтров в шапке доски: менеджер, тег, источник, дата создания (сегодня / вчера / 7 дней / 30 дней / свой период).
- Фильтры применяются на сервере (GET списка заявок), комбинируются (AND), сохраняются в localStorage, кнопка «Сбросить».
- Счётчик «N заявок» с учётом фильтров. На телефоне фильтры — в bottom sheet по кнопке «Фильтры (N)».

═══ ЧАСТЬ 2 — Поиск без запроса на каждую букву ═══
- Поиск по имени/телефону — debounce 300 мс, от 2 символов, отмена предыдущего запроса (AbortController).

═══ ЧАСТЬ 3 — Сумма бюджета в шапке колонки ═══
- В шапке колонки: количество и сумма `budget` заявок колонки («12 · 840 000 ₸»), с учётом фильтров.

═══ ЧАСТЬ 4 — Режим «Список» ═══
- Переключатель «Доска / Список» в шапке (запоминается). Список — таблица: имя, телефон (по праву), этап (цветом), менеджер, источник, теги, бюджет, создана, последнее действие. Сортировка по колонкам, клик по строке — LeadDrawer.
- На телефоне по умолчанию «Список» карточками.

═══ ЧАСТЬ 5 — Мобильная доска ═══
- ≤640: одна колонка на экран, горизонтальный scroll-snap между этапами, сверху полоса с названиями этапов (тап — перейти).
- Перенос заявки на телефоне без drag: в карточке кнопка «Этап ▾» → список этапов → тот же StagePopup подтверждения, что и при перетаскивании.
- Проверить LeadDrawer на iOS (fixed-позиция не прыгает при открытии клавиатуры).

═══ ЧАСТЬ 6 — Дубли при создании заявки ═══
- В окне «+ Заявка» при вводе телефона (после 11 цифр) — запрос на сервер: есть ли открытые заявки и клиент CRM с этим телефоном (`crm_clients.phone` — только цифры 7XXXXXXXXXX).
- Найдено — жёлтое предупреждение со ссылками: «Уже есть заявка „…“ в этапе „…“ (менеджер …)» / «Это клиент CRM: …». Кнопки «Открыть существующую» и «Всё равно создать».
- Создание дубля — запись в ленте заявки «Создана при наличии дубля …».

═══ ЧАСТЬ 7 — «Не удобно говорить» → «Отложенное решение» ═══
- Найди, где в чек-листе / исходах разговора есть вариант «Не удобно говорить» (контент этапов `leadStageContent.ts`, настройки этапов). Если такого варианта нет — добавь его в исходы первого контакта в настройках этапа (через существующий механизм вариантов id/label, task 81).
- Выбор «Не удобно говорить» → заявка не теряется: переходит в этап «Отложенное решение» и получает задачу «Перезвонить» на завтра (время — как у задач перезвона сейчас), менеджер — текущий.

═══ ЧАСТЬ 8 — Комментарии Fitbase в ленту заявки ═══
- Пока Fitbase работает: шаг синка `/note?client_id=X` → лента активности заявки (тип «Комментарий Fitbase», автор и дата из Fitbase), без дублей (уникальность по id заметки Fitbase).
- Пагинация по 100, пауза 300–500 мс, 4xx не ретраить, circuit breaker не обходить. В DRY ничего не писать в Fitbase (только читаем).
- Отдельно проверь и запиши в отчёт: приходят ли сообщения WhatsApp / чата Fitbase через `/note` (пункт «Проверка» из таблицы Сергея).
