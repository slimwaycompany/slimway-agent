## Часть 1 — Изменение к части 5 (QR)

- Все тесты InBody (QR и CSV) хранятся в `inbody_tests`, `source = 'qr' | 'csv'`
- Часть 5 уже сделана с записью в `body_measurements.inbody` — переделать на `inbody_tests`, существующие данные перенести
- Повторный скан того же листа не создаёт дубль (`unique inbody_id + tested_at`)

## Часть 2 — Импорт CSV (вкладка «Замеры», только admin)

- Кнопка «Импорт InBody» → загрузить `inbody270_data.csv` (LookinBody, UTF-8 с BOM, запятая, 103 колонки)
- Заголовки вида «1. ID», «6. Weight», …; ID в угловых скобках: `<87767681579>`
- Нормализация phone: 11 цифр (8/7 начало) → +7 + 10; 10 цифр → +7 + все 10; иначе null
- Дата «2026.08.31 17:56:13» — местное время Asia/Yekaterinburg (+05:00)
- «-» → null; «level 10» → 10
- Маппинг колонок:
  - 1. ID → inbody_id / phone; 2. Height → height; 3. Gender → gender; 4. Age → age
  - 6. Weight → weight; 18. BFM → bfm; 30. PBF → pbf; 24. SMM → smm; 21. FFM → ffm
  - 27. BMI → bmi; 62. VFL → vfl; 53. InBody Score → inbody_score; 59. WHR → whr; 58. BMR → bmr
  - Все 103 колонки → data (jsonb); исходная строка CSV → raw
- Предпросмотр: всего строк / новых / дублей / привязано / не привязано
- Импорт пачками, дубли пропускаются; повторная загрузка добавляет только новые
- Итог: «Добавлено N, пропущено дублей M, без клиента K»

## Часть 3 — Привязка к клиентам

- Клиент ↔ тест по `phone_digits` (inbody_tests) = `phone_digits` клиента (body_clients / fitbase_clients_cache)
- Если клиент есть в кэше Fitbase, но нет в body_clients — карточка всё равно показывает InBody
- Экран «InBody без клиента» (admin): список непривязанных тестов, ручная привязка поиском

## Часть 4 — Показ в карточке клиента

- Блок «InBody» (под «Потеряно»): последний тест — оценка, вес, % жира, жир кг, мышцы кг, висцеральный жир, ИМТ с нормами и цветом; дата
- График: вес, мышцы, % жира по всем тестам (переключатели)
- Таблица всех тестов, свернута по умолчанию
- «Потеряно со старта» → жир кг = bfm первого − bfm последнего; передавать в fat_kg_lost
- Клик по зоне (часть 6): сегменты из последнего теста — ffm_ra/bfm_ra, ffm_la/bfm_la, ffm_rl/bfm_rl, ffm_ll/bfm_ll, ffm_tr/bfm_tr
- Отчёты: колонка «InBody» (кол-во тестов)
