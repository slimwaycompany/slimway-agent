# Задача 48 — Напоминания пробных: фикс DRY, только неподтверждённым, имя, ночной перенос

## Части

1. DRY не должен блокировать боевой режим (не писать в script_reminders в DRY, только вернуть план)
2. Ставить только неподтверждённым, не по кругу; отменять при статусе 1/2/3/4; отслеживать пропавшие/изменённые визиты
3. Имя (vars.Имя → fitbase_clients_cache → без имени) и язык (vars.lang → KZ-детект)
4. Только 24ч и 3ч; TRIAL_1H_ENABLED=false; ночной перенос 3ч на 21:00 вечера
5. Тексты — строго по ТЗ (см. ниже)
6. Нет диалога → failed + watch_alert; 401/403 → alert + стоп
7. Проверка, документация, коммит
