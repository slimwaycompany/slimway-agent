## Часть 3 — Закрытие смены (Х-отчёт)

Открывается из задачи «Закрыть кассу» во вкладке «Менеджер» и кнопкой «Закрытие смены» там же.

- Данные из Fitbase (только ЧТЕНИЕ): продажи, возвраты, изъятия, внесения за сегодня (Asia/Yekaterinburg). page_size ≤ 100, пагинация. Если метода нет — написать в отчёте.
- Разделить по способу оплаты: наличные / безналичные
- Сумма на начало смены = counted_cash последнего закрытия ДО сегодняшнего дня. Если закрытий нет — ввод руками
- Наличные: приход, расход, остаток = начало + приход − расход
- Безналичные: приход
- Возвраты, внесения, изъятия — отдельными строками
- Расходы: список «сумма + на что», добавление строк
- Окно подсчёта по купюрам: 500, 1000, 2000, 5000, 10000, 20000; монеты 200, 100, 50, 20, 10, 5, 2, 1. Ввод количества → сумма сразу
- Расхождение = посчитано − ожидаемый остаток, подсветка если не 0
- Поля «Расхождения по операциям CRM» и «Прочие расхождения» (текст)
- Сохранение в cash_closings: одна запись на дату, повторное закрытие обновляет. closed_by = display_name. Операции Fitbase → fitbase_ops
- Печать (скрытый iframe): лист 1 — «Закрытие смены №…» по образцу templates/zakrytie-smeny.xlsx; лист 2 — список операций Fitbase за день
