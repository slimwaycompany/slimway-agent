═══ ЧАСТЬ 2 — Компонент окна абонемента (новый макет) ═══
- Вынести окно из `ClientsPage.tsx` в отдельный файл `kviz/client/src/pages/crm/PlanWindow.tsx`. Один компонент, два режима:
  - `mode="client"` — абонемент клиента (`crm_client_plans`), данные из части 1;
  - `mode="template"` — шаблон из Настроек (`crm_plans`), без данных клиента (часть 4).
- Строить на общем `Modal` из `components/ui/` (на телефоне — bottom sheet). Добавить в Modal размер `size="xl"`: ширина `min(1200px, 96vw)`, высота `min(860px, 92vh)`; стили в `index.css` рядом с `.ui-modal-sheet--wide`. Окно открывается поверх карточки клиента (проверь z-index поверх `.cp-overlay`).
- Макет `mode="client"` — две колонки (левая ~55%, правая ~45%), каждая колонка прокручивается сама:
  - **Левая колонка, сверху вниз:**
    - Шапка: название абонемента крупно (22px, жирный) + плашка статуса; ниже мелко «Fitbase», если source = fitbase.
    - **Цена — крупно:** 32px жирный, `price` из абонемента; под ней мелко «Продавец: <sold_by>».
    - **Вид оплаты** (новое): по каждому способу из `sale.payments` строка «Наличные — 30 000 ₸», «Kaspi — 29 000 ₸» (иконка по kind: cash — Banknote, cashless — CreditCard, deposit — Wallet, bonus — Gift). Ниже мелко «Чек №<number> от ДД.ММ.ГГГГ · кассир <cashier>». Если в чеке были и другие позиции (`items_count > 1`) — приписка «оплата за весь чек, сумма чека <total> ₸». Нет данных — «Вид оплаты: нет данных».
    - **Состав — крупно и заметно:** отдельный блок на всю ширину колонки. По строке на аппарат/пул: слева имя аппарата 18px жирный + мелкая подпись фазы (Активная / Завершающая), справа остаток крупно 24px «10 / 12» и полоса прогресса (осталось/всего). Пул Cross — имена через « / » и одна полоса. Безлимит — «∞» (с дневным лимитом — «1 в день»). Fitbase-абонемент без строк состава — одна строка «Сеансы: остаток/всего».
    - 4 даты (сетка 2×2, как сейчас): Куплен · Активирован · Предв. окончание · Окончание (до <с доп. сроком>).
    - «Когда действует» (если задано) — `formatPlanRestriction`.
    - Заморозка: «Использовано N из M дн.» + история заморозок из `freezes` (дата, «Заморозка на N дн.» / «Разморозка», причина, автор).
    - Кнопки внизу левой колонки (как сейчас, по `canEdit`): Заморозить (active), Разморозить (frozen), Распределить (needs_split).
  - **Правая колонка — «Посещения»:**
    - Заголовок «Посещения · N» и строка счётчиков: Пришла N · Не пришла N · Поздняя отмена N · Отменена N.
    - Ниже список сверху вниз на всю высоту окна (своя прокрутка): дата ДД.ММ.ГГГГ, время, аппарат, статус цветом (attended — `--success`, no_show — `--danger`, late_cancel — `--warning`, cancelled — `--text-3`). Fitbase-строки с мелкой пометкой «Fitbase».
    - Пусто — «Посещений по этому абонементу нет».
- Планшет 641–1024: две колонки остаются, если ширина окна ≥ 900px, иначе одна колонка, посещения под левой частью. Телефон ≤640: bottom sheet, одна колонка, порядок: шапка → цена → оплата → состав → посещения → даты → заморозки → кнопки.
