## Часть 1 — Поиск клиента в расписании

Строка поиска правее метки дня (`dateNav`). Поиск по ФИО и телефону, фильтрация загруженных броней (клиентская сторона). От 2 символов, 250 мс дебаунс.

- Совпавшие брони — outline primary (2px) + полная непрозрачность; несовпавшие — opacity 0.2
- Счётчик «N из M» + кнопки ↑↓ (`scrollIntoView` по `data-bid`)
- Дропдаун «Ближайшие записи» — до 10 ближайших броней (сервер), клик → переход на дату + имя в строке поиска
- Esc/✕ — сброс

Сервер: `GET /kviz/api/crm/schedule/client-bookings?search=...` → `[{ id, booking_date, starts_at, device_type_code, status, client }]`

## Часть 2 — Фильтр по меткам

Кнопка «Метки ▾» в `dateNav`. Три группы чекбоксов:
- Автометки (код `al:`)
- Теги клиентов (код `ct:`)
- Этикетки записи (код `bl:`)

ANY match = совпадение. Комбинируется с поиском (AND). Значок-каунтер «Метки (N)» при активных фильтрах. Сохраняется в localStorage.

## Часть 3 — Особые дни филиала

Таблица `crm_branch_hours_exceptions` (branch_id, day date, is_open bool, note text).

Три эндпоинта (право `settings.branch`):
- `GET /kviz/api/crm/branch/exceptions`
- `POST /kviz/api/crm/branch/exceptions` → `{ ok, conflict_count }` (conflict_count = брони booked/confirmed/attended на закрываемый день)
- `DELETE /kviz/api/crm/branch/exceptions/:day`

`schedule/day` → `special_day: { is_open, note } | null`

SchedulePage: banner с заметкой под dateNav; для закрытого дня — заметка под «Филиал не работает».

BranchSection: блок «Особые дни» — форма добавления + список исключений.
