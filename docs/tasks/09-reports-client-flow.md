### Часть 5 — Настройки: новые действия
«Перенести клиентов InBody»: для каждого phone_digits из inbody_tests — создать body_clients если нет, иначе связать. Имя из кэша Fitbase или номер.
«Выгрузить все результаты»: пройти всех клиентов, посчитать потери, upsert в studio_results. Предпросмотр → подтверждение → итог.

### Часть 6 — Результаты студии
Inline ТВ-экран со счётчиками (см, кг, жир, клиенток). Admin: скопировать ссылку, fullscreen, таблица с кликом → /reports/client/:id.

### Часть 7 — Факт дня и Дневной такт
Два отдельных маркетинговых отчёта. Данные из Supabase. Фильтры: период, источники, менеджер.
- Факт дня: что произошло в период (лиды созданы, в работе, записи на пробное, пришли, продажи)
- Дневной такт: судьба лидов созданных в период (новые → квалифицированы → записались → пришли → купили)
Клик по шагу → список людей.
