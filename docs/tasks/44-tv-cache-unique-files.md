ЗАДАЧА 44: ТВ — уникальные имена файлов, кэш immutable, ошибки загрузки под блоком
═══════════════════════════════════════

Причина: картинки сохранялись под фиксированными именами (promo/promo.jpg).
Адрес не менялся, /kviz/api/tv/media отдавал max-age=86400.
Браузер показывал старую картинку после замены и после удаления.

## Часть 1 — Бэкенд src/http/tv.ts
- promo-upload: UUID-имя, без upsert, старый файл удаляется после update, tvNotify()
- uploadResultImg: UUID-имя, без upsert, старый путь удаляется после update, tvNotify()
- proxyMedia: immutable-кэш для публичного прокси; no-cache для admin-прокси
- Ошибки Storage/Postgres только в console.error; пользователю — русский текст

## Часть 2 — Фронт SettingsPage.tsx
- promoErr: ошибки загрузки/удаления акции отображаются под блоком акции (не в верхнем баннере)
- resultErr[id]: ошибки загрузки фото результата отображаются под соответствующей карточкой
