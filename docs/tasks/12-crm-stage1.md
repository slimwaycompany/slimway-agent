# Задача 12: CRM этап 1

## Части

### Часть 0: SQL таблицы
Таблицы `crm_*` созданы Сергеем вручную в Supabase. SQL не создаём.

### Часть 1: Новые вкладки в shell
Порядок: Менеджер | Агент | Расписание | Клиенты | Воронка | Касса | Квалификация | Замеры | Отчёты | Настройки

- Расписание, Воронка, Касса — PlaceholderPage «В разработке»
- Настройки — только admin
- Повторный клик по активной вкладке сбрасывает iframe на домашний URL

### Часть 2: Страница Настройки (admin only)
Левый сайдбар 220px + контентная область.

Разделы: Аппараты, Абонементы, Услуги, Товары и склад, Поставщики, Промокоды, Виды оплаты, Рекламные источники, Занятия, Сервис

Сервис содержит: Настройки InBody, Импорт InBody, Выгрузка результатов, Миссия студии (перенесены из Отчётов).

### Часть 3: Страница Клиенты
Список с поиском и фильтрами + карточка клиента.

Форма создания/редактирования: ФИО, телефон (+7-маска, уникальность), ИИН (12 цифр, авто-DOB из 6 цифр + определение века), дата рождения, рекламный источник (+реферер), кем выдан, действителен до, фото (Supabase Storage `crm-client-photos`), противопоказания, примечания.

Приватность: admin видит полный ИИН, manager — первые 6 + «******».

Импорт из Fitbase: page_size≤100, пауза 400мс, дедупликация по fitbase_client_id.

### Часть 4: Стиль
Glassmorphism, #02BDB6/#263CD9, компактные формы, ₸, архивирование вместо удаления.

### Часть 5: Проверка на проде
На стороне Сергея.
