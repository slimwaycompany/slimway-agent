# Задача 68.1 — Тема в профиле, токены, перевод всех цветов

Полный текст ТЗ сохранён в чате UX/UI (19.11.2026).

## Коротко

После задачи 68 тёмная тема включалась по системе Windows → экраны остались светлыми (~2300 hex-цветов в .tsx). Текст «терялся». 

**Цель:** тема — личная настройка сотрудника (app_users.ui_theme), каждая страница правильная в обеих темах.

## Части

1. Тема в профиле вместо системы — убрать prefers-color-scheme, читать из базы, PUT /kviz/api/me/theme
2. Где переключать — Настройки → «Моё → Оформление» (для всех), меню пользователя на десктопе
3. Токены — добавить --surface-3, --overlay, --input-bg, --input-border, --focus-ring, --row-hover, --row-alt, --glass-strong; проверить контраст
4. Перевод ВСЕХ цветов экранов на токены (~2300 hex + ~35 rgba)
5. Каждая страница в обеих темах
6. check:mobile с .env, двумя темами и автоконтрастом
7. Правила в CLAUDE.md/AGENTS.md, документация

## SQL выполнен

```sql
ALTER TABLE app_users ADD COLUMN IF NOT EXISTS ui_theme text NOT NULL DEFAULT 'light' CHECK (ui_theme IN ('light', 'dark'));
```
