# Задача 08: кнопки обновления, закрытие смены, новая вкладка «Отчёты», фильтры продаж, загруженность, вкладка после перезагрузки

Статус: 🔧 в работе

## Часть 1 — Кнопки обновления (Unauthorized)
Кнопки «Обновить Fitbase» / «Обновить данные за день» вызывают /run/* (CRON_SECRET).
Нужны сессионные API /kviz/api/ops/sync и /kviz/api/crm/sync (admin).
Lock от двойного запуска. Время последней синхронизации рядом с кнопкой.

## Часть 2 — Закрытие смены: правки
- Автообновление при открытии
- Дата смены = сегодня (начало/конец из staff_shifts, иначе 08:00 / 22:00 или 20:00 сб-вс)
- Кнопка «Обновить» видна на 375px (не обрезается)
- Пересчёт цифр после обновления без перезагрузки

## Часть 3 — Вкладка «Отчёты» (доска блоков)
Видна всем; внутри блоки по роли:
- Консультант → Замеры (отчёты переезжают из вкладки Замеры)
- Смены → отметки, фильтр по сотруднику/периоду
- Личные задачи → сводка за период, по дням
- Маркетинг → Воронки (Метрики переезжают сюда; вкладку Метрики убрать)
- Управляющий → Продажи, Занятия (только admin)
- Результаты студии → текущий экран + ссылка для ТВ

## Часть 4 — Продажи: «Обновить FB» и фильтры
Кнопка «Обновить FB» + выпадающие фильтры с множественным выбором:
кассир, менеджер, товар, тип оплаты, тип операции. Excel с фильтрами.

## Часть 5 — Занятия и загруженность
Источник: fitbase_visits (resource, abonement).
Фильтры: период, аппарат, абонемент/услуга, статус.
Сетка день×час с цветом, итоги, разбивка. Excel.
