# Задача 13: CRM Настройки — фикс схемы и форм

## Части

### Часть 0: Главное правило
Формы Настроек делались не по схеме базы — отсюда ошибки Postgres в окнах. Каждая форма сверена с таблицами crm_*. SQL уже применён вручную: добавлена crm_suppliers.link; у crm_payment_methods.kind значения cash / cashless / deposit / bonus.

Допустимые значения (строго):
- crm_devices.type_code: vacuactiv | infrastep | infrashape | rollshape
- crm_devices.default_phase: active | finishing
- crm_devices.status: working | repair | disabled | broken
- crm_plans.kind: abonement | service
- crm_plan_items.phase: active | finishing
- crm_payment_methods.kind: cash | cashless | deposit | bonus
- crm_promo_codes.discount_type: percent | fixed
- Числовые поля с DEFAULT в базе → 0, не null

### Часть 1: Аппараты
- Дропдаун «Фаза по умолчанию» (Активная/Завершающая)
- Дропдаун «Статус» (Работает/В ремонте/Отключен/Неисправен)
- Авто-номер следующего свободного для выбранного типа
- Дублирующийся номер → «Аппарат VacuActiv №1 уже есть»
- Цветной badge статуса в списке

### Часть 2: Абонементы/Услуги
- Inline «Состав» (crm_plan_items): тип устройства + фаза + кол-во сеансов + удалить строку
- Фаза предзаполняется из дефолтной фазы аппарата
- Атомарная запись план + состав (ошибка состава → откат плана)
- Поля: auto_activate_days, max_deferred_start_days (был пропущен)
- Список показывает состав: «VacuActiv 12 (акт.) · RollShape 12 (зав.)»
- Заголовок «Новая услуга» (был «Новый услуг»)

### Часть 3: Поставки/Поставщики
- Поставщик в поставке — обязательное поле
- «+ Новый поставщик» → inline мини-форма; после сохранения авто-выбирается
- Все поля поставки обязательны
- Поставщик: поле link (кликабельная ссылка)

### Часть 4: Виды оплаты
- Только cash/cashless для создания пользователем
- Системные (deposit, bonus): только переключатель is_active, без редактирования и удаления
- Badge «нал»/«безнал» в списке

### Часть 5: Удаление + архив везде
- Кнопки «В архив» и «Удалить» для всех разделов
- ConfirmModal вместо browser alert
- Проверка использования перед удалением с дружелюбными сообщениями
- «Показать архив» + «Восстановить»
