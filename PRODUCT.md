# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Сотрудники студии SlimWay (Астана): менеджеры по продажам, администраторы, управляющие. Работают за компьютером в офисе и за стойкой, изредка с телефона. Задачи: принять клиента, закрыть смену, просмотреть замеры, зафиксировать продажу.

## Product Purpose

Рабочее окно студии SlimWay: единая точка для работы с CRM, замерами, кассой, отчётами и расписанием. Заменяет разрозненные инструменты (Fitbase, таблицы Google) единым интерфейсом с быстрым доступом ко всем нужным данным.

## Positioning

Инструмент для конкретной студии с конкретным бизнес-процессом; не универсальная CRM, а рабочее окно «как у нас в студии».

## Operating Context

- Используется в офисе и у стойки администратора.
- На компьютере (1440 px) — основной сценарий; телефон — проверить данные на ходу.
- Параллельно открыт чат Fitbase (EasyChat), иногда несколько вкладок браузера.
- Данные синхронизируются из Fitbase по расписанию; собственная CRM (crm_* таблицы) — основная.

## Capabilities and Constraints

- Веб-приложение, PWA без service worker.
- Одна студия, одна роль-владелец (admin), несколько менеджеров.
- Все данные в Supabase (Postgres); сервер Node.js на Render (512 МБ, один процесс).
- Нет Tailwind; CSS — ручные токены + React-компоненты.
- Нет нативных обёрток; мобильная версия — мобильный браузер.

## Brand Commitments

- Фирменные цвета: #02BDB6 (основной, бирюзовый), #263CD9 (акцент, синий).
- Стиль: светлый воздушный glassmorphism.
- Шрифт: Manrope.
- Язык интерфейса: русский. Деньги: ₸.

## Product Principles

1. Быстро и плотно: меньше кликов, меньше прокрутки, больше данных на экране.
2. Телефон — равноправный канал: не ужатый десктоп, а настоящий мобильный интерфейс.
3. Единый стиль: один источник токенов, один набор компонентов, никаких локальных override.
