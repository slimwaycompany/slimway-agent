# Скриптолог SlimWay — расширение Chrome

Боковая панель с деревом скриптов продаж для менеджеров SlimWay.

## Установка

1. Скачайте и распакуйте папку `extension/` на компьютер.
2. Откройте Chrome → `chrome://extensions`
3. Включите **Режим разработчика** (переключатель в правом верхнем углу).
4. Нажмите **«Загрузить распакованное»**.
5. Выберите папку `extension/`.
6. Закрепите значок расширения на панели браузера (значок пазла → закрепить «Скриптолог SlimWay»).

## Использование

1. Откройте страницу Fitbase: `https://slimway.fitbase.io/...`
2. Нажмите значок расширения — откроется боковая панель.
3. Введите логин и пароль (те же, что у рабочего окна SlimWay).
4. Откройте чат клиентки в Fitbase — панель автоматически подхватит имя и телефон.
5. Идите по скрипту: читайте текст, жмите **«Вставить в чат»**, отмечайте ответы клиентки.

## Обновление

При изменении скриптов на сервере расширение **не нужно переустанавливать** — оно загружает дерево при каждом открытии.

При изменении файлов расширения:
1. Замените папку `extension/` на новую версию.
2. В `chrome://extensions` нажмите кнопку **«Обновить»** на карточке расширения.

## Иконки

Положите файлы `icon48.png` и `icon128.png` в папку `extension/` (иконка 48×48 и 128×128 px в цветах бренда: `#02BDB6` / `#263CD9`).
